# ASCII Art Animation

1. As your first user-visible update, give a rough estimate of work time in the user's language, accounting for scene complexity, verification, and requested exports. This is not playback duration. Start immediately unless a missing input or required permission blocks you. Update materially changed estimates.
2. A subject alone is enough. For example, `보름달이 뜬 파리의 에펠탑` needs no format instructions. By default deliver one standalone offline HTML with a portrait 9:16 frame: **74% ASCII art above, 26% typing replay of actual renderer code below**, silent autoplay, no visible buttons. Never replace this default with art-only, a Studio, or a movie unless the user explicitly requests a different output.
3. Copy [assets/ascii-scroll-shell.html](assets/ascii-scroll-shell.html) to a descriptive new filename. Replace **only** the block between `BEGIN AUTHORED SCENE` and `END AUTHORED SCENE` as specified in [references/scene-contract.md](references/scene-contract.md). Do not alter the layout, source pane, layer build logic, or playback clock. If the template is missing, say what is missing instead of claiming to meet the fixed format with a substitute.
4. Write original named layer functions for the requested subject. Draw with monospaced ASCII glyphs; the art should be identifiable even without a title. Choose a visible motion payoff if none is specified. The template starts genuinely blank, progressively draws the actual glyph calls while typing excerpts from each layer’s actual renderer and following new lines, then starts motion at its own time zero after the opening composition is complete. It replays real source excerpts with a caret and follows new lines during build and motion. Label this as typing replay, not live generation. Never substitute canned code or an image behind a mask. Reduced-motion mode shows a composed still with matching source lines.
5. Verify the actual output before delivery: the shell outside the scene block is unchanged; it runs offline, has no visible controls or horizontal overflow, and its small-screen frame shows both panels. Check the blank start, a partial glyph build with matching source text typing into view, and the motion payoff after the build. If some checks cannot run in this host, say which ones. Do not claim to have tested another host.
6. If asked for an actual video, render and deliver a playable file of the fixed two-panel animation by default, capturing from the blank start and including the real renderer typing replay. Exclude browser chrome. Prefer MP4; try WebM if MP4 is unavailable or fails. Verify that the file opens and check its dimensions and duration. Include the HTML unless the user asks for video only. If encoding is unavailable, report it and provide the HTML, not a claim that video was made. A request for editable settings or do-it-yourself export may get a separate [Studio](assets/studio-shell.html); do not substitute Studio's static code excerpt for the scrolling demo in a video.

Keep public outputs free of reference images, third-party implementation code, private paths, and development notes. Do not publish unless requested.
